# Pulse Maze

Минималистичная браузерная игра: точка выходит из кругового лабиринта, поворачивая
стрелками, а радиально перемещаясь по данным BLE-пульсометра.

## Требования

- Node.js 20 или новее и npm;
- современный Chromium-браузер с поддержкой Web Bluetooth;
- HTTPS при публикации приложения: Web Bluetooth доступен только в защищённом
  контексте. `localhost` подходит для локальной разработки.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173/`). В
обычном режиме подключите совместимый BLE-пульсометр кнопкой «Подключить
пульсометр».

## Debug-режим без пульсометра

Откройте точный адрес:

```text
http://localhost:5173/?debugHeartRate=true
```

В этом режиме BLE не используется. После 20-секундной калибровки:

- `ArrowLeft` и `ArrowRight` поворачивают точку по секторам лабиринта;
- `ArrowUp` повышает виртуальный BPM на 1;
- `ArrowDown` понижает виртуальный BPM на 1.

Debug-панель показывает технические параметры только при наличии параметра
`debugHeartRate=true`; в обычном интерфейсе она отсутствует.

Перед первой игрой отображается напоминание остановиться при головокружении или
дискомфорте.
