# Стадия 1. Основа приложения и круговое движение

## Цель

Получить запускаемое Vue-приложение с адаптивным Canvas и точкой, которая
двигается по окружности клавиатурой.

## Работы

- Инициализировать Vue 3 + TypeScript + Vite и настроить базовые глобальные
  стили.
- Создать `App.vue`, `GameHeader.vue`, `GameCanvas.vue`, `useGameLoop.ts`,
  `useKeyboardInput.ts`, `game/config.ts`, `game/types.ts` и
  `game/player/polarMath.ts`.
- Хранить игрока как `{ radius, angle }`; рендерить точку через вычисленные
  Canvas-координаты.
- Добавить постоянную угловую скорость и обработку `ArrowLeft`/`ArrowRight`.
- Реализовать масштабирование Canvas с квадратной рабочей областью и поддержкой
  `devicePixelRatio`.

## Проверка готовности

Canvas корректно меняет размер окна, а точка движется по окружности с одинаковой
скоростью при разной частоте кадров. Тесты покрывают нормализацию угла.
