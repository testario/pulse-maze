# Стадия 4. Debug-управление пульсом

## Цель

Полностью протестировать радиальное управление без устройства.

## Работы

- Добавить `useHeartRateControl.ts`, `utils/median.ts` и `utils/clamp.ts`.
- Реализовать экспоненциальное сглаживание BPM и определение направления по
  `baselineBpm`, `outwardThreshold`, `inwardThreshold` и `radialSpeed` из
  конфигурации.
- Включать эмулятор только при `?debugHeartRate=true`. `ArrowUp` и `ArrowDown`
  плавно меняют BPM с шагом 1; начальное значение — 70 BPM.
- Связать направление пульса с радиальной скоростью игрока и существующими
  коллизиями.
- Выводить в debug-режиме baseline, raw/smoothed BPM, радиус, угол и ячейку.

## Проверка готовности

Повышение виртуального BPM выводит игрока наружу, возврат к baseline перемещает
его к центру, нейтральный диапазон останавливает радиальное движение. В обычном
интерфейсе debug-информация отсутствует. Тесты покрывают сглаживание, медиану и
определение направления.
