# Стадии разработки Pulse Maze

Этот каталог делит [полное ТЗ](../../pulse-maze-spec.md) на независимые,
последовательные стадии. Каждая стадия завершается работающим `npm run dev`.

## Общие правила

- Новые пороги, скорости и размеры добавлять в `src/game/config.ts`, а не
  дублировать литералы в модулях.
- Игровая логика должна быть независима от Vue и Canvas, чтобы рендерер можно
  было заменить позднее.
- Тесты добавлять вместе с чистой бизнес-логикой, а не откладывать всё покрытие
  до конца.
- UI должен сохранять минимализм из ТЗ; техническая телеметрия разрешена только
  при `?debugHeartRate=true`.
- Не начинать Bluetooth-интеграцию, пока управление, коллизии и генерация
  лабиринта не работают с debug-эмулятором.
