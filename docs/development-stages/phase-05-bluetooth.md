# Стадия 5. Bluetooth-пульсометр

## Цель

Заменить debug-источник данных реальным BLE Heart Rate Service, сохранив
эмулятор для разработки.

## Работы

- Создать `useBluetoothHeartRate.ts` и чистый парсер Heart Rate Measurement.
- Запрашивать устройство только по кнопке «Подключить пульсометр» и подключать
  GATT, сервис `0x180d`, характеристику `0x2a37` и notifications.
- Поддержать 8- и 16-битный BPM в данных характеристики.
- Добавить `ConnectionScreen.vue`, состояния подключения и их отображение в
  `GameHeader.vue`.
- Обработать отсутствие Web Bluetooth, отмену выбора устройства, ошибки GATT,
  разрыв соединения и повторное подключение.

## Проверка готовности

Поддерживаемый пульсометр подключается по явному действию, текущий BPM
отображается и обновляет управление. Ошибочные и неподдерживаемые сценарии не
оставляют приложение в промежуточном состоянии. Парсер BLE покрыт unit-тестами.
